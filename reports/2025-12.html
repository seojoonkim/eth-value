How this page is made

Composite = simple average of the models that have a stored value that day (12 models; the same rule as the 01.3 fair value band chart). Band edges = composite × 0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0. Past values are recomputed from the stored daily data with the current model formulas and constants, so they can differ from what the live page showed on that day. Days without data are left out, never filled. Built 2026-10-25 09:30 UTC.
